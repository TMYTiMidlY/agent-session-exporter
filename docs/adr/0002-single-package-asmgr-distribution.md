# ADR 0002：单一 `asmgr` 包与统一命令入口

## 状态

已接受。产品范围见 [ADR 0001](0001-scope-archive-and-restore.md)。

## 背景

项目曾把解析、HTML、Markdown 和 CLI 拆成多个可发布包，但外部用户只有一个命令行入口，也没有独立消费内部模块的稳定 API。多个包会扩大版本、安装和兼容性边界，却没有形成独立产品。

## 决策

- 对外只发布一个无 scope 的包和一个同名命令 `asmgr`。
- 解析、搜索、渲染和命令实现保留为仓库内部模块，不承诺独立包级 API。
- HTML、Markdown、备份及后续输出形式都是同一工具的能力，通过子命令暴露，不各自塑造成产品。
- 不同分发渠道应共享同一命令模型；受运行时或打包限制而不可用的能力必须在用户文档中明确标注。

## 后果

- 仓库名可以保持描述性的 `agent-session-manager`，用户入口统一为 `asmgr`。
- 内部模块可以随实现重构；只有 CLI 行为和归档格式需要保持兼容。
- 发布流程、运行时差异和具体安装命令属于当前运维事实，放在 README 的[维护者：版本与发布](../../README.md#release)和[安装](../../README.md#install)章节，而不是固化为架构决策。
